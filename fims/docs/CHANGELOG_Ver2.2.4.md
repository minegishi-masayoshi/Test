# FIMS Cloud Ver.2.2.4

## FMU map-selection fix

- Province mode zoom is limited to the selected Province boundary.
- Concession mode zoom is limited to the selected Concession boundary.
- Clicking an FMU no longer changes the map extent.
- FMU client-side highlight and popup were disabled because they could pan or distort the map when their geometry did not align with the WMS display.
- FMU table-row selection and status display remain active.
