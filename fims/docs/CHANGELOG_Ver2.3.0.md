# FIMS Cloud Ver.2.3.0

## Legacy report catalog

- Added selectable report buttons based on the report objects identified in
  `Report_FIMS_forNew_Backup.accdb`.
- Grouped reports into National, Province, Concession and Reference categories.
- Preserved the existing Preview and Export CSV toolbar as placeholders for
  the next implementation stage.
- No report calculation, layout reproduction or PDF generation is implemented
  in this release.
- Automatic map zoom remains disabled.
