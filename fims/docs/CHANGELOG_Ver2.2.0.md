# FIMS Cloud Ver.2.2.0

## Concession–FMU spatial linkage

- Clicking a Concession now selects it.
- FMUs whose Polygon/MultiPolygon geometry intersects the selected Concession are displayed in the shared object table.
- The map displays the selected Concession together with the related FMUs.
- Summary is recalculated from only the related FMUs.
- Province selection resets the Concession selection and returns to the Concession list.
