# FIMS Cloud Ver.3.6.2

## Nationwide recalculation

- Added `All Provinces` calculation mode for nationwide imported data.
- Each Province is calculated and committed independently.
- Added nationwide result totals, Province success/failure counts and total updated FMUs.
- Retained Selected Province mode for testing and partial recalculation.

## Summary completion flow

- Added `Refresh Summary & Close`.
- The Large Map notifies the opener window after calculation.
- The Province page reloads the currently selected FMUs and immediately refreshes Summary.
- The Large Map then closes.
