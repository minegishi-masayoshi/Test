# FIMS Cloud Ver.2.8.0

## Large Map MVP

- Standalone Large Map window added.
- Embedded Province Map removed from the main screen.
- Selected Province/FMU context is transferred through URL parameters.
- GeoServer WMS layers can be switched on and off.
- Province and FMU WFS geometry is loaded for focus/highlight where available.
- Import and FMU Calculation remain disabled placeholders for later phases.
