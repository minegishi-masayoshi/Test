# FIMS Cloud Ver.3.1.0

## Large Map UI refinement

- Removed `Last Data Update`.
- Removed `Administrator Guidance`.
- Reduced the workflow bar height and changed it to a compact graphical sequence.
- Added graphical step symbols for Import, Review, Calculate and Results.
- Initial Large Map display now loads only the selected Province boundary.
- Province FMU geometry is no longer loaded automatically on opening Large Map.
- FMU and Concession layers are displayed later during result review.
- Replaced the browser-native file selector display with an English custom control:
  `Browse GeoPackage... / No file selected`.
- Increased the effective map display area.
