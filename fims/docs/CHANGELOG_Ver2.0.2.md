# FIMS Cloud Ver.2.0.2

## Province Summary

- Recreated the Province Summary in the same two-column arrangement as the legacy FIM-ADMIN Province screen.
- Left column: Area(ha), Protected, external constraints, and serious constraints.
- Right column: 1975 forest area/volume, logged land use, and revised forest area/volume.
- Retained Province-level aggregation, FMU count, metadata, and CSV/report data APIs.
- Added responsive stacking for narrower screens.
